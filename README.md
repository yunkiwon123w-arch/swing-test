# 한국주식 스윙 백테스트 웹앱 v0.1

휴대폰 브라우저에서 조건을 설정하고 서버에서 백테스트를 실행하는 Streamlit 앱입니다.

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 표시되는 주소로 접속합니다.

## 클라우드 배포
Streamlit Community Cloud, Render, Railway 등 Python 웹앱 호스팅 환경에 올릴 수 있습니다.

배포 후에는 휴대폰에서 해당 웹주소만 열면 됩니다.

## 기본 전략
- 기준봉 +10% 이상
- 거래대금 1,000억원 이상
- 기준봉 거래량: 직전 20일 평균의 2배 이상
- 종가 5일선 위
- 5일선 및 20일선 상승
- 기준봉 이후 2~5거래일 눌림
- 눌림 거래량: 기준봉의 50% 이하
- 눌림일 종가가 기준봉 저가 위
- 다음 거래일 눌림일 고가 돌파 시 진입
- -3% 손절
- 10거래일 추적

모든 주요 숫자는 웹 화면에서 변경할 수 있습니다.

## 결과
- 최종 거래 수
- +5%, +7%, +10%가 -3% 손절보다 먼저 도달한 비율
- 손절률
- 평균 MFE / MAE
- 평균 10거래일 수익률
- 종목별 상세 결과
- CSV 다운로드

## 주의
KRX/pykrx 데이터 요청은 서버 환경과 네트워크 상태에 따라 제한될 수 있습니다.
장기간 전체시장 검증은 시간이 걸릴 수 있으므로 캐시나 데이터베이스 방식으로 확장하는 것이 좋습니다.
